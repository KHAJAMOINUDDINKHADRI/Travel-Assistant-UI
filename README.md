# ✈️ Travel Assistant UI

A single-page React application that simulates a travel recommendation chat experience for a traveler visiting Tokyo and Kyoto on a long trip. The app features a conversational interface on the left pane and contextual visuals (photos, overview, activity cards) on the right pane.

## 🎯 Usage

1. On load, the chat window simulates a greeting and suggests two initial activities:
   - 🏎️ Nighttime Go-Karting in Shibuya (Adventure + Fun)
   - 🍵 Tea Ceremony in Gion (Culture + History)
2. The visual panel displays photo cards and maps for each suggestion.
3. The user “chooses” an option (fixed demo reply).
4. The system presents two more activities and asks for confirmation.
5. The user confirms, and the final confirmation message appears.

## 🛠 Tech Stack

- **React** (Frontend library for building user interfaces.)
- **TypeScript** (Strongly typed JavaScript for better code quality.)
- **Vite** (Fast build tool for modern web projects.)
- **TailwindCSS** (Utility-first CSS framework for styling.)
- **Lucide Icons** (Icon library for React components.)

## 🚀 Getting Started

### Prerequisites

- **Node.js** v16+ and **npm** installed.

### Installation

1. **Clone the repo**
   ```bash
   git clone https://github.com/KHAJAMOINUDDINKHADRI/Travel-Assistant-UI.git
   cd Travel-Assistant-UI
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```

### Running the App

```bash
npm start
```

Open `http://localhost:5173` to view it in your browser.
